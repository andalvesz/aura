# Private Workspace Skills

Skills com `privateWorkspace: true` e `allowedWorkspaceSlugs`.

## Alvesz Experience Skill

- Existe apenas no workspace `alvesz`
- Reutiliza CRM, propostas, eventos e estoque (`workspace.alvesz`)
- Não aparece para novos usuários / listPublicSkills sem membership
- Não é exportada em configuration export
- Exige membership + role ≥ member
- Não é instalável cross-workspace

Consórcios permanece removido e não reaparece como skill ou capability.
