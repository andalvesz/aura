# Business Modes

Modos operacionais do Business Expert (não são engines novos):

| Mode | Uso típico |
|------|------------|
| Afiliado | Distribuição / comissão |
| Produtor | Produto próprio |
| Prestador | Serviço unitário |
| Agência | Entrega com processo |
| Startup | SaaS / escala |
| Empresa Local | Operação de bairro/cidade |
| Creator | Audiência → oferta |
| Freelancer | Serviço individual premium |

## API

```ts
import {
  listBusinessModes,
  setBusinessMode,
  recommendModes,
} from "@/lib/business-expert";
```
