# Product Builder

Fluxo para **criar um produto** (curso, pack, SaaS light, etc.).

## Perguntas

- Qual problema resolve?  
- Público  
- Formato  
- Ticket  
- Prazo  

## Saídas

- Nome, promessa, oferta  
- Módulos e bônus  
- Estrutura de oferta  
- Projeto + plano (core Planner)

## API

```ts
import { runProductBuilder } from "@/lib/business-expert";
```
